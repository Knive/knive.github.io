# Design system

(IN PROGRESS, submit to change)

Palette sourced from dagger materials (steel blade, aged copper guard, dark stone floor):

- `--void: #07090D` — page background
- `--stone: #0F1318` — section backgrounds
- `--steel: #A4B0BA` — body text, blade color
- `--copper: #8C6D3F` — accent, worn metal
- `--moonlight: #D6DCE5` — headings
- `--ember: #C9813A` — hover/CTA (firelight)
- `--sapphire: #3A5F8A` — secondary accent

Typography:

- Display/headings: Cinzel (Google Fonts, 400/600) — classical Roman letterforms
- Body: Cormorant Garamond (Google Fonts, 400/500) — archaic editorial
- No tracked-out ALL CAPS labels, no em-dash label chrome, sentence case everywhere
